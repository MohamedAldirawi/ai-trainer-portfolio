# Hands-On Portfolio Artifacts

This folder contains structured artifacts that complement the 12 portfolio case studies. They are **simulated, self-directed examples** created to demonstrate practical AI-training, evaluation, annotation, prompt-engineering, and quality-assurance work.

The artifacts are intentionally separated from the narrative case studies so a reviewer can inspect concrete outputs and structured records rather than relying only on prose.

| Project | Artifact | Demonstrates |
|---|---|---|
| 01 | [response-evaluation.csv](response-evaluation.csv) | Rubric scoring and correction decisions |
| 02 | [prompt-iterations.csv](prompt-iterations.csv) | Prompt versions and measurable refinement |
| 03 | [text-annotation.csv](text-annotation.csv) | Structured labels, confidence, and rationale |
| 04 | [finance-evaluation.csv](finance-evaluation.csv) | Domain-aware financial evaluation |
| 05 | [instruction-following.csv](instruction-following.csv) | Requirement-level PASS/FAIL decisions |
| 06 | [bias-fairness-evaluation.csv](bias-fairness-evaluation.csv) | Structured fairness annotations |
| 07 | [hallucination-fact-check.csv](hallucination-fact-check.csv) | Claim verification and error classification |
| 08 | [financial-analysis.csv](financial-analysis.csv) | Independent calculations and verified results |
| 09 | [financial-annotation.csv](financial-annotation.csv) | Financial entity/value annotation |
| 10 | [qa-error-log.csv](qa-error-log.csv) | QA findings, severity, root cause, and action |
| 11 | [training-workflow.yaml](training-workflow.yaml) | End-to-end training workflow record |
| 12 | [data-quality-qa.csv](data-quality-qa.csv) | Dataset defects, corrections, and readiness |

## Portfolio Integrity

These artifacts are **not paid client work, production datasets, or professional AI employment evidence**. They are practical portfolio exercises designed to make the methodology inspectable and reproducible.

# Portfolio Evidence

This directory contains compact, reproducible evidence artifacts supporting selected AI Trainer portfolio projects.

## Purpose

The main project pages explain the methodology. The evidence files show how that methodology can be applied to structured examples.

## Transparency

These are **simulated, self-directed portfolio exercises** created to demonstrate practical capability. They are not presented as client work, paid AI employment, or proprietary datasets.

## Evidence Set

| Artifact | Demonstrates | Related projects |
|---|---|---|
| `response-evaluation-sample.md` | Rubric-based scoring and error annotation | 01, 05, 10, 11 |
| `prompt-iteration-sample.md` | Prompt iteration and output comparison | 02 |
| `finance-evaluation-sample.md` | Domain-aware financial evaluation | 04, 08 |
| `financial-annotation-sample.md` | Structured finance annotation | 09 |
| `data-qa-sample.md` | Dataset QA and readiness decisions | 03, 12 |

## Evidence Standard

Each artifact should make the following visible where relevant:

1. Input or task
2. Evaluation criteria
3. Decision or label
4. Evidence supporting the decision
5. Correction or improved output
6. Final quality check

## Important Principle

A portfolio should demonstrate capability without implying professional experience that has not occurred. Evidence is therefore labeled as simulated and self-directed throughout the repository.
